# Mama Product Management System

A web-based product and production management system developed as an early university project.

The system was designed to manage product-related operations, including purchasing, inventory checking, production, stock replenishment, receiving, and delivery.

## Main Features

- Product management
- Product inspection and stock checking
- Purchase Requisition (PR)
- Purchase Order (PO)
- Product requisition
- Receive order management
- Production management
- Production result and production loss tracking
- Batch management
- Supplier and customer management
- Delivery management
- Quotation and receipt management
- Payment and accounting management
- Employee and user management
- User groups and access control
- Activity logs

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## About This Project

This project was developed during my early years at university to practice web application development and database management. It focuses on managing product, purchasing, inventory, and production processes within a single system.
